## Role Description

Designed and delivered backend services and cloud infrastructure for AWS’s capacity-planning platform, helping establish the foundation used to run large-scale planning and optimization workloads.

- Built core platform capabilities across APIs, workflow orchestration, containerized compute, data persistence, monitoring, and infrastructure as code.
- Redesigned core allocation logic to correctly account for buffered demand in capacity plans.
- Modernized compute infrastructure and the Python runtime to cut optimization runtime.
- Created the platform’s first comprehensive unit-test suite and its first end-to-end integration tests, run through the CI/CD pipeline.

Primary technologies: Java, Python, TypeScript, AWS CDK, API Gateway, Lambda, Step Functions, ECS, AWS Batch, DynamoDB, S3, CloudWatch, and Docker.
