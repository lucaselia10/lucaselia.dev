# Architecture decision records

ADRs preserve individual architectural decisions. They are not the whole system description.

| Document                                                        | Role                                                               |
| --------------------------------------------------------------- | ------------------------------------------------------------------ |
| [Design history](../design-history.md)                          | Key decisions and turning points, in order.                        |
| [System design](../system-design.md)                            | The current integrated system.                                     |
| [Roadmap](../roadmap.md)                                        | Planned work and completion gates.                                 |
| [Portfolio experience V1](../design/portfolio-experience-v1.md) | Product specification for the portfolio UI.                        |
| [Deployment readiness](../deployment-readiness.md)              | Checks required before any AWS deployment.                         |
| [Evaluation](../../tests/evaluation/README.md)                  | Route expectations for questions. It does not score model wording. |
